# Datary 0.2.4 — publication and documentation quality

Datary 0.2.4 improves how the existing software is installed, evaluated, archived, and cited.
It does not claim new recording, analysis, plotting, or security behaviour.

## What changed

- Expanded the Zenodo description into sanitizer-safe HTML with practical capabilities,
  installation, quick-start, application, limitation, documentation, related-software, and
  citation sections.
- Expanded `CITATION.cff` and synchronized creator, repository, release-date, keyword, version,
  and verified concept-DOI metadata.
- Reworked the README navigation and release-facing examples, and added a documentation index.
- Regenerated the checked-in noisy-sensor session and report with Datary 0.2.4 so the example
  metadata and integrity hashes describe the current release.

## Install

```bash
python -m pip install https://github.com/devkyato/Datary/releases/download/v0.2.4/datary_lab-0.2.4-py3-none-any.whl
datary --version
```

The expected version output is `datary 0.2.4`.

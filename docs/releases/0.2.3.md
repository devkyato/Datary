# Datary 0.2.3 — citation and archival metadata

Datary 0.2.3 prepares the project for archival publication. It adds Zenodo metadata and a
CITATION.cff file while keeping the local-first recording, validation, analysis, replay,
comparison, plotting, and reporting workflow unchanged.

## Install

```bash
python -m pip install https://github.com/devkyato/Datary/releases/download/v0.2.3/datary_lab-0.2.3-py3-none-any.whl
```

Use the Zenodo concept DOI `10.5281/zenodo.21849618` for the archive family and see
[`CITATION.cff`](../../CITATION.cff) for machine-readable citation metadata.

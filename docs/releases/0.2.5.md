# Datary 0.2.5 - CLI messaging

Datary 0.2.5 clarifies overwrite conflicts and rejects incomplete `compare` invocations at the CLI.
Recording, analysis, plotting, and session behaviour are otherwise unchanged.

## What changed

- Clarify overwrite conflicts with an explicit `--overwrite` hint.
- Reject `compare` invocations that provide fewer than two sources at the CLI.
- Update package, citation, archival, README, and issue-template version references to 0.2.5.

## Install

```bash
python -m pip install https://github.com/devkyato/Datary/releases/download/v0.2.5/datary_lab-0.2.5-py3-none-any.whl
datary --version
```

The expected version output is `datary 0.2.5`.

# Datary 0.2.1 — checked-in evidence integrity

Oh! The final check after publishing 0.2.0 found a small but real reproducibility defect in the
example session. Python's CSV writer emitted CRLF on Windows, then Git correctly normalized that
tracked text to LF. The content still parsed, but its bytes no longer matched the SHA-256 recorded
before the commit.

I did not want to explain that away as “only an example.” An example session is evidence too.
Datary 0.2.1 makes every CSV-producing path choose LF explicitly, regenerates the example, and
adds a byte-level regression assertion. A fresh clone now verifies the example session exactly.

All analytical, parser, security, streaming, packaging, and documentation changes from 0.2.0
remain unchanged. This is a focused alpha patch release.
